# Homebrew tap

Homebrew casks for macOS apps maintained by [Josip Musa](https://github.com/josipmusa).

## Beanvan

[Beanvan](https://github.com/josipmusa/beanvan) helps nearby teammates coordinate coffee breaks from the macOS menu bar. It requires Apple Silicon and macOS 14 or newer.

```sh
brew install --cask josipmusa/tap/beanvan
```

Beanvan is not notarized. If macOS blocks the first launch, try opening it once and then approve it under **System Settings > Privacy & Security > Open Anyway**.

## Watt

[Watt](https://github.com/josipmusa/watt) shows Claude and Codex subscription usage in the macOS menu bar. It requires Apple Silicon and macOS 14 or newer.

```sh
brew install --cask josipmusa/tap/watt
```

Each app's release workflow updates this tap automatically when a new semantic-version tag is published.
